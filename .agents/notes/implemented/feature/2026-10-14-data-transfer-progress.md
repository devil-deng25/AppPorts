# Agent Note: 数据迁移按真实工作阶段显示进度

Status: implemented

## Problem

微信等大目录在复制前读取内容、复制后校验和清理时可能耗时较长。原弹窗只显示复制字节数，完整校验期间会停在 100%，清理又把字节归零；用户无法判断正在做什么。仅显示计时动画也不能证明文件系统仍有进展。

> 后继决定：[后台迁移任务与异常处理](../architecture/2026-10-21-后台迁移任务与异常处理.md)引入带阶段权重的任务总进度，替代本篇不使用固定权重的呈现选择；实际工作计数、活动时间及持久化完成依据仍保留。

## Decision

数据目录和自定义目录共用阶段弹窗。只有复制阶段且总字节数已知时显示百分比，并明确其范围是文件复制。准备、扫描、同步、校验、入口切换、清理和恢复使用系统活动指示、阶段解释、总耗时与阶段耗时。

每个目录操作拥有一个 `DataTransferProgress` 快照，`DataTransferSession` 通过 TaskLocal 传递观察器；脱离原任务取消状态的恢复任务显式传递观察器。原有扫描、散列读取、同步和删除在完成实际工作时更新当前项、读取量和本轮项数，不额外遍历文件树。

自动收尾任务自己持有快照。“继续处理”通过一次观察回调接入同一个对象，因此加入已经运行的后台任务也能看到它的真实进度。中断恢复中核对部分文件的读取同样报告活动。

弹窗以 250 ms 间隔读取小快照，工作线程只更新受锁保护的数据，不为每个文件派发主线程任务。读取快照不刷新活动时间；15 秒没有新活动时显示距离上次进展的时间。复制速率超过 3 秒无新活动即隐藏。每次独立遍历重置本轮计数，批量中的下一个目录使用新对象。

复制器原有可等待的回调和取消检查保持原来的顺序。扫描、同步和校验直接更新观察器，不向原字节回调插入事件；数据迁移服务的准备和收尾消息带有明确阶段。界面观察状态不能授权切换或清理，不增加整项超时，也不降低内容校验要求。

- 其余命中“校验／清理”的签名备份、所有权和旧基线重试决定属于执行安全约束，不被此呈现改动吸收或替代。

## Alternatives considered

- **只补旋转动画和计时器**：改动小、没有跨模块观察器，但无法解释当前文件工作，也容易把界面仍在刷新误认为存储仍有进展。
- **每个扫描或删除节点都异步回调主线程**：与现有复制回调形式统一，但需要改动同步安全检查的调用边界，大量小文件还会产生不必要的任务与视图更新。
- **为各阶段分配固定比例的总进度**：可以保留一个持续增长的百分比，但扫描、复制、校验和清理的时间比例取决于文件数量和磁盘，固定权重会制造错误的完成预期。

## Testing

`DataTransferProgressTests` 验证已知与未知复制总量、零字节文件、阶段切换、无活动提示、速率过期、遍历计数及操作隔离；临时数据真实复制、核验和清理后，阶段与内容符合预期。`OperationMaintenanceProgressTests` 使用可控任务验证前台接入后台工作时共享观察器，后续操作得到新观察器。

异步阶段测量以直接等待的闭包调用 TaskLocal，沿用调用方的任务与取消状态；不为测量创建新任务。Xcode 27 回归覆盖嵌套阶段的父状态恢复、同一会话与返回值传递，以及真实任务取消后的异常传播和绑定清理。

通过 `script/isolate_test_host.py` 创建独立测试宿主，再用 `xcodebuild test-without-building` 运行相关目录迁移、应用事务、复制、挂载恢复、准备恢复、同步和资源叉测试。回滚用例将故障样本从已经支持的 FIFO 改成目录外硬链接，继续验证原有所有权回滚断言；修正后的挂载迁移套件通过。

`LocalizationAuditTests` 通过；23 条新文案覆盖全部 22 种语言，原有 1273 条文案条目保持一致。`MigrationSafetyRenderTests/testRenderDataTransferProgressStages` 渲染准备、扫描、复制、校验、清理和等待的 24 个组合，覆盖中文、英文、长路径与明暗模式。Release `xcodebuild clean build` 通过。

## Consequences

复制完成后的校验与清理有独立解释和实际工作量，避免用 100% 或重新归零的复制字节数代表整个操作。当前文件和计数帮助用户观察进展；总耗时和阶段耗时在暂时没有文件事件时仍可阅读。

系统命令或阻塞的文件系统调用不能提供内部百分比；弹窗只报告已知阶段和最后活动时间，不宣称任务健康或预计完成时间。观察器增加每个读取块／节点的小锁开销，但不增加数据读取。合成测试不代替真实微信 36 GB 数据的迁移性能测量。
