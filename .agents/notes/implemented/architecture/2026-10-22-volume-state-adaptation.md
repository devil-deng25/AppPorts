# Agent Note: 卷盘点与清理退避适配后台任务和加密卷

Status: implemented

## Problem

基于 1.9.3 的本地卷分类实现需要迁到当前 main。当前版本新增后台任务、用户清理选择与加密卷；旧实现的 schema 10 已与当前清理选择冲突。反复校验无法完成的副本浪费读盘，但暂停清理不能阻止恢复应用入口。

旧实现同时包含不成立的删除依据：私有暂存路径不证明内容没有变化，活跃卷非空不证明历史备份没有独有数据。部分测试删除了原来的变更注入和保护断言，不能当作行为已验证的证据。

## Decision

沿用当前事务、内容清单、操作锁和用户清理选择。A–J 是诊断类别，不是删除授权；E1/E2 区分已有可用入口与需要恢复入口。盘点覆盖挂载记录、挂载迁移事务、旧清理记录与孤儿卷，使用一次 APFS 清单及独立分配的系统挂载表快照。诊断在入口恢复和重挂后、释放操作锁后执行；命令最多 5 秒、输出上限 1 MiB，原始磁盘输出不写日志。查询失败必须保留为未知，离线不声称卷已被删除。

昂贵清理按 60、300、1800、7200、86400 秒退避，之后每天最多一次，不永久停止。间隔从实际失败时刻起算；检查与计数落在每条保留副本的执行入口，后继的清理不能越过前驱自己的期限。TaskLocal 将自动/手动语义传给挂载、软链及独立恢复任务。只有已经确认原入口可用的中断收尾可以退避；入口未恢复时继续协调，正常重挂不受退避影响。手动重试绕过时间限制，但不绕过 keep/deferred 的现有选择语义或任何内容/身份校验。

退避事实使用可选字段；实际写入调度字段才升级到 schema 11，清空字段也不降低格式版本。保留材料内嵌恢复记录的调度字段同样校验。拒绝未知未来格式，不把保留版本号误当作保留未知字段；不宣称旧版本能回退读取新版账本。保存退避失败应记录错误。

当前复制器已排除未共享普通 `.DS_Store`，并在删除时重新捕获及验证实际文件；保留该实现，补接线测试，不迁入旧的预先 unlink 和重建根时间戳方案。`.TemporaryItems` 可含真实临时数据，不加入删除白名单。任何新增业务内容、同名目录/链接/共享硬链接继续保留。

保留的还原暂存也必须有内容证据。`verifiedCopySnapshot` 返回通过旧基线校验的那一次目标观察，不能先验证、再另拍一份现场快照当删除基线。部分副本使用 `partialCopySnapshot`，源卷通过独立 UUID 证明后允许设备号在重挂后变化。删除前把具体清单写入保留材料，冷启动按同一清单核验剩余项；源入口身份、写入者检查、父目录身份仍必须成立。无基线或新增/改写业务内容继续保留，不因它位于私有路径就删除。

孤儿卷只报告。恢复丢失记录需要当前真实卷 UUID、精确标记、受管路径和锁内重新观察的完整证据；本轮不以卷名或孤儿类别删除卷。

## Alternatives considered

- **整批移植本地 diff**：保留实现最完整，但会覆盖任务调度、用户清理选择和加密契约，并迁入无内容证明的删除路径。
- **五次失败永久停试**：读盘次数有明确上限，但短暂离线或应用长期运行会变成永久不收尾；保留每日上限与手动入口。
- **清理前删除固定名字再改快照**：能处理访达改写，但现有复制器已解决普通 `.DS_Store`，预先删除会增加竞态并可能扩大到真实临时数据。

## Testing

回归覆盖 A–J 分类、E1/E2、加密等待、外来卷占用、查询失败、路径权限与 000 占位；盘点包含活动挂载、旧清理、保留材料和孤儿卷，诊断输出仅含分类计数、完成状态与时间。

维护接线测试覆盖七轮失败、到期和手动重试、长校验从失败时刻计时、前驱退避、保留选择、旧清理记录与入口恢复。文件系统测试保留内容变更和唯一新文件的拒删断言，检查 `.DS_Store` 普通文件与目录/软链/共享硬链接的差别，验证持久化删除清单的冷重试。schema 2–10 缺字段可读，schema 11 保存加密事实，未知未来格式和非法调度拒绝且不改原文件。

三处上游测试在未修改的 `511a137` 临时副本上同样失败：元数据冲突现由 marker 安装阶段报告并保留已发布但未启用的候选；页面锁已迁到任务中心；目录时间戳不单独参与内容比较。本次同步这些断言，保留源、候选内容、拒绝再次迁移和实际锁独占的检查。没有删除或跳过失败用例。

## Consequences

后台重复清理受持久化时间表约束，异常盘点可区分未知、等待与需恢复入口。代价是每条失败多一次账本写入，以及一次有界诊断查询；到期后仍要重新读取内容，不能靠盘点类别授权删除。没有内容证明的旧记录仍会占空间，每日检查不保证未知副本可以自动删除。旧版本不能读取 schema 11，未知字段不会靠保留版本号自动得到保护。

盘点是时间点观察，A–J 只用于诊断，C 表示当前不可用而不证明卷已删除；分类总数统计记录和孤儿观察，并非物理卷去重计数。真实断电、用户磁盘和钥匙串测试不能由 fake disk 成功代替。
