# 常见问题与排查

先保存工作，记下 AppPorts 显示的状态和错误提示。涉及数据不可见或迁移中断时，保留原盘与现有副本，再按下面的现象检查。

## 应用打不开或打开后立即退出 {#launch}

先确认原外置盘在线、本地入口没有变成“孤立链接”。如果出现“签名已替换”，或升级 macOS 27 后才发生问题，按[升级与修复](/docs/macos-27)处理。没有这类提示时，检查原应用是否支持当前系统，并保留错误信息；不能把所有启动失败都归因于签名。

## 应用能打开，但原来的数据不见了 {#missing-data}

先退出应用，避免继续向新建的空目录写入。打开 AppPorts，确认对应数据为“已挂载”或链接正常，再检查原应用是否获准访问可移动宗卷。外盘上的文件还在，并不等于原应用已接到这些文件。若本地和外部都出现新内容，保留两份，反馈具体路径类型与状态，勿直接互相覆盖。

## 显示“外置盘未连接”或“孤立链接” {#offline}

重新连接原盘，在 Finder 或磁盘工具中检查设备是否出现，必要时解锁，再刷新 AppPorts。若卷在线但显示“待挂载”，使用“挂载”。这些状态可能只是暂时离线；确认原盘和目标位置后仍异常，再[导出诊断信息](/docs/faq#feedback)。

## 挂载迁移的检查没有通过 {#mount}

先在“准备情况”检查权限、连接、格式和加密状态；安装位置与本次所需空间，以点击迁移后的检查提示为准。当前容器挂载迁移要求未加密 APFS 存储；其他内容不应一概套用这一要求。可以更换目标或保留本地数据，详见[外置盘准备](/docs/storage-guide#apfs)。

## 提示目标已存在、保留副本或清理未完成 {#conflict}

先核对本地与外部各自是什么内容。“目标冲突”需要确认归属；“保留副本”或清理失败则可能表示主体操作已完成，但收尾尚未结束。按界面提供的重试或保留选项处理，不要重复迁移、手工删除备份或覆盖同名目录。恢复入口与搬回本地的区别见[还原与接回](/docs/restore)。

## 迁移中断后应该重来吗 {#interrupted}

保持原存储连接，先查看 AppPorts 的恢复提示。中断可能发生在复制、切换或清理阶段，各阶段留下的有效副本不同。保留程序提示的临时目录和备份；无法判断时记录最后一步和错误，不要自行选一份删除。

## 哪些内容不适合迁移 {#compatibility}

系统应用、受保护的容器结构、整个用户目录，以及相互包含的受管目录都有额外限制。虚拟机、数据库和正在下载的游戏库还可能有后台写入，操作前必须完全停止使用它们。AppPorts 能识别一个目录，不代表该应用支持把它搬到任意存储。应用已有自己的存储位置设置时，也可优先使用官方方式。

## 为什么不允许移动某些容器目录 {#protected}

有些目录承担系统结构作用，例如容器根目录和特定临时目录。即使文件复制和挂载都成功，应用也可能拒绝启动。目录列表中的保护提示需要保留，具体原因见[容器结构实验](/docs/blog/data-migration-boundaries#starting-point)。

## 如何更新迁移后的应用 {#updates}

先查看是否有“锁定迁移”或“非锁定迁移”提示。受保护的应用可能需要迁回、更新后再迁出；系统管理的 App Store 外置安装有自己的更新流程。按[应用更新说明](/docs/core#updates)处理，勿为了更新直接删除外部副本。

## 为什么磁盘工具里多了 AppPorts 数据卷 {#volumes}

这些可能是挂载迁移创建的专用卷。它们通常不会一直显示在 Finder 边栏，但仍存放实际数据。需要撤销迁移时使用 AppPorts 的“还原”，不要在磁盘工具中直接抹掉或删除这些卷。

## 外盘上的 AppPorts Backups 能删除吗 {#signature-backups}

这是手动重签前保存官方应用原包的文件夹，不是聊天记录或文档备份。确认不再需要恢复材料、也没有操作待完成时，可以在 Finder 中删除对应原包；当前安装和个人数据不受影响，但之后恢复官方状态可能需要重新取得官方安装包。AppPorts 也会自动清理已证明冗余的原包，详见[保存与清理规则](/docs/settings#signature-backup-cleanup)。

恢复提示找不到原包时，先连接保存它的那块盘，确认文件夹仍在原位置。即使应用没有迁出内盘，新原包仍保存在外盘；没有合适外盘时，新的官方应用重签会在修改正式应用前停止。

## 删除 AppPorts 前要做什么 {#uninstall}

先还原仍由它管理的容器数据，并确认完成清理。单独删除程序不会把数据搬回本机，还可能使自动接回失去所需程序。迁移过的应用和普通数据也建议先按[还原说明](/docs/restore)检查，明确它们目前存在哪里。

## AppPorts 会自动上传我的文件吗 {#privacy}

迁移操作在本机进行，日志与诊断包也先保存在本地。检查更新、加载赞助名单等功能会访问网络，因此不应把应用描述为完全离线。具体信息和接收方见[隐私政策](/docs/privacy)。

## 怎样反馈问题 {#feedback}

在 [GitHub Issues](https://github.com/wzh4869/AppPorts/issues) 描述 AppPorts 与 macOS 版本、外置盘格式、发生的操作、完整错误提示，以及问题是否可重复。通过菜单栏“日志 → 导出诊断包”获取记录，提交前检查是否含私人路径或内容。诊断包不会自动上传；不要公开聊天记录、账户资料或无关文件。
