# 开源许可

AppPorts 的实现与文档使用了以下项目。使用或分发时，请遵守各项目的许可证。

## AppPorts {#section-1}

AppPorts 使用 [Apache License 2.0](https://github.com/wzh4869/AppPorts/blob/main/LICENSE)。应用图标由本项目制作。

## 参考与使用的第三方项目 {#section-2}

目录体积扫描等实现参考了 [Pearcleaner](https://github.com/alienator88/Pearcleaner)。它以 **Apache 2.0 with Commons Clause** 发布，这是源码可见的 fair-code 许可，并非 OSI 认可的开源许可。

除 Apache 2.0 条款外，Commons Clause 还禁止“销售”以该软件功能为主要价值的产品或服务。使用时需保留完整许可证，包括：

```text
Software: Pearcleaner
License: Apache 2.0 with Commons Clause
Licensor: alienator88
```
