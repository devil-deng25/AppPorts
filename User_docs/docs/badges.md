# 徽章与状态

徽章说明项目现在的状态，不是一次完整的健康检查。先看文字，再决定是否需要处理；可点击的徽章会补充说明。不同版本可能显示不同组合。

## 应用位置与更新保护 {#apps}

| 看到的徽章 | 表示什么 | 接下来怎么做 |
| --- | --- | --- |
| 本地 | 应用在 Mac 上，没有其他需要显示的标签。 | 想释放空间时再迁移。 |
| 已链接 | 已有指向外部应用的本地入口。 | 连接外置盘后正常使用。 |
| 锁定迁移 | 已链接，并为需要保护的应用启用了更新保护。 | 更新前阅读[应用更新说明](/docs/core#updates)。 |
| 非锁定迁移 | 此应用需要更新保护，但目前未锁定。 | 点击了解原因；更新前先确认处理方式。 |
| 部分链接 | 文件夹内只有部分应用或组件已链接。 | 展开或查看对应项目，逐项确认。 |
| 孤立链接 | 本地入口还在，目前找不到外部目标。 | 先连接原外置盘并刷新，不能据此断定文件已删除。 |
| 未链接、外部 | 外部应用尚无可用的本地入口。 | 需要时使用“链接回本地”。 |
| 待迁出 | 识别到本地真实应用比外部副本更新。 | 核对版本和目标，再将本地新版迁出。 |

“锁定迁移”保护的是特定更新场景，并不替代备份。“待迁出”也不是必须立即执行的命令。

## 应用类型 {#types}

| 徽章 | 含义与注意事项 |
| --- | --- |
| 运行中 | 应用正在运行，迁移或还原前先保存并退出。 |
| 系统 | macOS 系统应用，通常不适合迁移。 |
| 非原生 | 在 Mac 上运行的 iPhone／iPad 应用。支持范围受设备与系统限制。 |
| 商店 | 来自 App Store，或由系统管理外置安装。支持时可点击查看说明。 |
| Sparkle、Electron | 应用使用的技术框架。它们有助于判断更新方式，不表示迁移已经成功。 |

## 签名状态 {#signing}

| 徽章 | 含义 | 建议 |
| --- | --- | --- |
| 签名已替换 | 检测到原开发者签名被本地重签替换。 | 打开“修复”或“查看修复步骤”，按[升级与修复](/docs/macos-27)处理。 |
| 签名待检查 | 当前签名或恢复材料的检查没有得到可靠结果。 | 先连接外盘，点击“检查签名”查看结果并保留备份；持续出现时提供诊断信息。 |
| 已重签名 | 当前识别为本地重签状态，但未归入上述开发者签名替换提示。 | 不代表已恢复官方身份，也不保证容器数据能访问。 |

签名状态与数据位置是两回事。“已挂载”不能证明应用签名正常，“签名已替换”也不能证明数据损坏。

已确认重签的应用，右键菜单保留“恢复原始签名”，不再同时提供重复重签入口；检查结果不明时先检查签名。新保存的官方原包在外盘，恢复前需接回保存它的盘，见[签名与修复](/docs/settings#manual-signing)。

## 数据目录与自选文件夹 {#data}

| 状态 | 表示什么 | 接下来怎么做 |
| --- | --- | --- |
| 本地 | 数据仍在本机。 | 核对用途后决定是否迁移。 |
| 已链接 | 原目录通过符号链接访问外部数据。 | 保持外盘在线。 |
| 已挂载 | 外部数据卷已接到原目录。 | 打开应用检查实际读写。 |
| 待挂载 | 已找到数据卷，但尚未接到原目录。 | 使用“挂载”。 |
| 外置盘未连接 | 暂时找不到受管数据卷。 | 连接原盘并检查卷是否可用。 |
| 待接回 | 外部数据仍在，本地入口需要重建。 | 核对目标后使用“接回”。 |
| 待规范 | 识别到受管链接，但位置需要整理。 | 阅读“整理”的确认说明；旧容器链接另见[经典模式](/docs/classic-mode)。 |
| 现有软链 | 已有符号链接，尚未按 AppPorts 的方式管理。 | 核对真实目标，按可用操作处理。 |
| 用户目录入口 | 容器中指向桌面、下载、图片等个人目录的快捷入口，并非此应用独占的数据。 | 不统计目标大小，也不提供迁移或还原；不要把它当作普通空文件夹。 |
| 孤立链接 | 自选文件夹的链接目标暂时不可达。 | 先检查外盘、路径和连接。 |
| 未找到 | 配置中的目录目前不存在。 | 核对原位置，不要先新建同名空目录。 |
| 外部 | 自选文件夹的数据位于外部位置。 | 结合本地一侧状态判断是否需要接回。 |
| 目标冲突 | 目标位置已有其他内容。 | 确认两份内容的归属，不能直接覆盖。 |
| 保留副本 | 操作后还有需要保留或继续清理的副本。 | 按完成提示收尾，先确认有效数据在哪。 |

## 重要、推荐、可选 {#priority}

这是数据目录的重要程度提示，不是迁移成功率：**重要**表示影响应用核心功能，**推荐**表示通常有较大空间收益，**可选**表示可能较小或可重建。迁移任何一类都需要先退出相关程序。

例如，“推荐 + 本地”只是说这个本地目录值得查看；“已链接 + 运行中”则说明外部应用正在使用。需要改变存放位置或恢复入口时，见[还原、接回与解除链接](/docs/restore)。
