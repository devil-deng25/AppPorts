# 更新日志

这里记录各版本当时的变化。**历史条目中的功能可能已经停用，不应直接当作当前操作步骤。** 当前正文按 1.9.1 开发版整理；旧功能的行为、版本和替代方法保存在[历史功能归档](/docs/archive/overview)。

## v1.9.1（开发中） {#v1-9-1}

以下按当前 **1.9.1 build 31** 整理，不代表已发布版本承诺：

- 应用数据列表默认隐藏不可迁移的锁定结构，可打开“显示锁定目录结构”查看原因；状态统计支持筛选，个人目录快捷入口单独标识，不再计入应用数据大小或提供迁移操作。
- 迁移进度分别显示准备、复制、校验和收尾等阶段。复制百分比到达 100% 后，仍需等待整次操作完成；长时间没有进展时会显示最后活动信息。
- 数据迁移与手动重签名分开，迁移不再自动附带签名操作。
- 手动重签前的完整官方原包自动保存到外盘可见的 `AppPorts Backups` 文件夹，附中英文说明；无需选择新位置，没有合适外盘时在修改正式应用前停止。内盘应用操作时仍需临时空间。
- 旧内盘有效原包在条件满足时自动迁出，冗余原包和失效旧记录按核验结果清理；仍有恢复价值或来源不明的材料继续保留，外盘离线不视为备份丢失。
- 签名菜单随状态变化：已重签的应用保留“恢复原始签名”，隐藏重复重签入口；恢复官方状态后重新显示符合条件的重签操作。
- 所有 macOS 版本停用开机自动重签名，并移除常驻设置卡。打开 AppPorts 时处理旧登录任务，仅清理失败时显示重试。
- 加强复制核验和容器结构保护，在切换或清理前再次检查数据状态。
- 保留经核对的原始应用恢复材料，区分“签名已替换”与“签名待检查”，通过修复面板处理旧迁移。
- 修复官方原包验签失败后仍可能继续重签的问题；校验失败或超时会停止。改进签名中断后的恢复，避免已撤回的操作被后台继续提交，或对已完成操作重复重签。

相关内容：[迁移数据](/docs/datamigrae/operation) · [签名原包](/docs/settings#signature-backups) · [升级与修复](/docs/macos-27) · [旧版自动签名归档](/docs/archive/data-signing)

## v1.9.0 {#v1-9-0}

- 容器数据默认采用挂载迁移：符合条件的数据进入未加密 APFS 专用卷，接到原目录，保留应用签名。
- 默认限制沙盒应用重签，保留需要确认风险的经典模式，并提供旧签名检查、完整备份与修复入口。
- 增加准备情况和迁移前检查，说明权限、安装位置、外盘格式、加密及空间要求。
- 改善登录和插盘后的数据接回，核对真实挂载位置；等待时间仍取决于磁盘和系统授权。
- 完善还原、备份和清理失败后的处理，改进数据目录树、行内操作、弹窗、本地化及项目支持入口。
- 当时在 macOS 27 上停用登录自动重签；1.9.1 开发版进一步在所有系统停用。

[查看 v1.9.0 发布](https://github.com/wzh4869/AppPorts/releases/tag/v1.9.0)。当时保留的迁移后重签与早期登录任务行为现已归入[历史功能说明](/docs/archive/data-signing#versions)。

## v1.8.0 {#v1-8-0}

### 新功能 {#v1-8-0-features}

- 新增自定义本地扫描目录：「Mac 本地应用」标题栏新增「+」按钮，可添加额外的本地应用扫描目录。适用于 JetBrains Toolbox、Steam 等将应用安装在非 `/Applications` 目录的工具。添加的目录会持久保存，并自动监控文件变化（#48）。
- 新增 Stub Portal 版本自动同步：外置硬盘上的应用通过 App Store 更新后，本地 Stub Portal 的版本信息会自动同步更新，并刷新 macOS Launch Services 缓存，「打开方式」菜单不再显示旧版本号（#50）。
- 新增工具目录识别：支持 Gradle（`~/.gradle`）、Android 开发数据（`~/.android`）和 Flutter/Dart Pub 缓存（`~/.pub-cache`）（#49）。
- 新增目录迁移：可在「目录迁移」标签中添加任意用户文件夹，将大型项目、模型、素材库或工具缓存迁移到外部存储，并支持接回和还原（#54）。
- 新增受保护应用迁移预警：迁移 App Store 应用或 root 归属应用前，会提示这类应用可能因权限不足无法自动删除或替换，并建议先通过 Finder 手动迁移后再创建链接（#55）。

### 改进 {#v1-8-0-improvements}

- 应用扫描性能优化：每个应用的 Info.plist 读取次数从 7 次降低到 1 次（通过内存缓存），整体扫描速度显著提升。
- 扫描超时保护：codesign 子进程新增 10 秒超时，避免大型应用签名检查卡死导致扫描挂起。
- 目录体积计算安全上限：递归计算应用体积时新增 50 万文件数量上限，防止 Electron 等超大应用包无限遍历。
- 扫描过程可追踪：扫描循环新增逐应用 TRACE 日志，便于定位扫描卡在哪个应用。
- 数据目录扫描精准匹配：修复 bundle ID 后缀提取逻辑，过滤 app、com、org 等通用词汇，避免误匹配系统容器目录导致扫描变慢。
- 工具目录接回检测更完整：本地工具目录缺失但外部存储规范位置仍有受管目录时，会显示「待接回」；切换外部存储会自动刷新工具目录状态。
- 本地化与无障碍完善：应用/数据目录/自定义目录状态、排序与筛选标签、设置开关和状态徽章会更稳定地跟随当前语言，并提供更明确的辅助功能标签。
- 应用体积改为会话级缓存，减少刷新后重新显示「计算中」或体积丢失的情况（#55）。
- 数据目录迁移回滚更安全：创建链接前先把本地源目录改名为隐藏安全备份；创建链接或清理备份失败时会尽量保留本地备份和外部副本，避免两端数据同时丢失（#54）。

### 修复 {#v1-8-0-fixes}

- 修复 Trae 等应用扫描极慢的问题 — bundle ID 中的通用后缀 `app` 导致 `~/Library/Containers/` 下大量不相关目录被误扫描。
- 修复外置硬盘应用通过 App Store 更新后，本地 Stub Portal 版本信息不更新、「打开方式」菜单显示旧版本的问题。
- 修复点击刷新按钮不会触发 Stub Portal 版本同步的问题。
- 修复数据目录接回或规范化时可能把外部普通文件当作目录处理的问题；现在会拒绝普通文件并保留原文件。
- 修复多行弹窗正文在部分语言下回退显示中文的问题，并补全俄语界面翻译；Stub Portal 的「外部存储未连接」系统弹窗也会按系统语言显示（#55）。

## v1.7.0 {#v1-7-0}

### 新功能 {#v1-7-0-features}

- 新增「待迁出」状态：当本地真实应用版本高于外部存储中的同名应用时，AppPorts 会标记为「待迁出」，提示可将本地新版迁移到外部存储并替换旧副本。
- 新增数据迁移重签名确认：迁移应用容器内数据前，可选择是否在迁移完成后自动对关联应用执行 Ad-hoc 重签名，以降低容器数据迁移后应用无法识别数据、提示异常或启动异常的风险（#44）。 **此处记录旧版行为，自动签名流程现已停用，见[归档](/docs/archive/data-signing)。**

### 界面改进 {#v1-7-0-ui}

- 顶部工具栏重排：应用页和数据目录页切换按钮改为更紧凑的图标 + 文本样式，减少空间占用。
- 数据目录页操作栏优化：「工具目录 / 应用数据」切换、迁移后重签名开关、恢复原始签名按钮和刷新按钮统一放入顶部工具栏。 **此处记录旧版行为，自动签名流程现已停用，见[归档](/docs/archive/data-signing)。**
- 应用状态徽章新增「待迁出」，方便识别本地版本高于外部旧副本、可以迁出替换的应用。
- 数据目录迁移重签名确认弹窗完成本地化，标题、正文和按钮会跟随当前语言显示。 **此处记录旧版行为，自动签名流程现已停用，见[归档](/docs/archive/data-signing)。**

### 改进 {#v1-7-0-improvements}

- 应用迁移安全策略增强：外部目标已存在时，仅在目标被识别为 AppPorts 管理的旧入口、旧迁移残留，或当前应用处于「待迁出」状态时，才会自动清理并继续迁移。
- 数据目录恢复校验增强：不再使用目录大小接近作为自动恢复依据，必须完整匹配 AppPorts metadata 后才会自动接回或恢复。
- 应用数据扫描更稳定：快速切换应用时，旧扫描任务结果不会覆盖当前选中应用的数据目录列表。
- 管理员命令和 AppleScript 转义增强：路径包含引号、反斜杠、空格或中文时，Finder 删除和管理员修复权限命令会更安全地处理。
- 本地化完善：修复切换语言后部分帮助内容、提示弹窗和数据迁移确认内容仍显示中文或翻译不完整的问题，并补齐所有支持语言的相关翻译（#43）。

### 修复 {#v1-7-0-fixes}

- 修复数据目录迁移可能将外部真实目录误判为可恢复目标的问题。
- 修复应用迁移时可能错误删除外部同名真实应用的问题。
- 修复外部旧 AppPorts portal / 旧迁移残留无法被稳定识别和清理的问题。
- 修复路径包含特殊字符时 AppleScript 或管理员命令可能构造错误的问题。
- 修复应用数据迁移流程中，后台迁移或迁移后重签名可能读取到已切换应用的问题。 **此处记录旧版行为，自动签名流程现已停用，见[归档](/docs/archive/data-signing)。**
- 修复「待迁出」状态未在应用列表中显示状态徽章的问题。

- 修复：原生 Stub Portal 被误识别为普通本地应用的问题。
- 修复：迁回本地时无法正确清理原生 Stub Portal 的问题。
- 修复：链接回本地时应用壳被当作完整应用处理的逻辑漏洞。
- 修复：AutoResignInstaller 安装失败时静默成功的问题。
