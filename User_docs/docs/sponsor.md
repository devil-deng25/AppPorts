## 留言说明

赞助时，请在留言（备注）中写下你的**昵称**；**个人链接可选**，GitHub 主页、个人博客、社交账号等都可以。

收到赞助后，我们会把「昵称 + 链接」收录，并展示在上面的名单以及 AppPorts 的「关于 AppPorts」页面中，感谢每一份支持。

::: tip 不想公开也没关系
未提供昵称时，我们不会展示赞助信息；提供昵称但没有链接时，仅展示昵称，不附带跳转链接。
:::

如需修改赞助名单中的昵称、个人链接或其他展示信息，请联系 [a@shimoko.com](mailto:a@shimoko.com)，并注明原昵称和需要修改的内容。

## 展示顺序

赞助者按以下规则排序：

| 优先级 | 排序规则 |
| --- | --- |
| 1 | 赞助金额从高到低 |
| 2 | 金额相同时，按赞助时间从早到晚 |

::: tip 金额不设门槛
赞助金额没有下限，也不影响你使用 AppPorts 的任何功能——它始终对所有用户完全免费。
:::
