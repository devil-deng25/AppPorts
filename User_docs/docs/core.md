# 迁移应用

应用迁移移动的是应用本体。聊天记录、项目、模型和缓存等数据可能仍在本机，需要另外使用[数据迁移](/docs/datamigrae/operation)。

## 迁移前 {#prepare}

连接外置盘，选择外部应用库，确认剩余空间。保存工作并完全退出要迁移的应用；重要内容先做好备份。系统应用和受保护的位置不适合直接移动，具体限制以 AppPorts 的提示为准。

## 迁移到外置盘 {#move}

1. 在“Mac 本地应用”列表选中应用。需要多选时，按住 Command 再逐个选择。
2. 点击“迁移到外部”，检查目标位置。
3. 若出现同名目标或版本选择，先核对两边内容。不要把不能确认的副本当成垃圾删除。
4. 等待 AppPorts 完成复制、检查和本地入口创建。
5. 从 Finder 或 Dock 启动应用，检查打开文件等常用功能。

完成后，外部应用库中能看到真实应用，本地保留[启动入口](/docs/glossary#local-portal)。进度接近完成时仍可能在核验或清理，请以最终结果为准。

如果应用不在默认扫描位置，可在“Mac 本地应用”标题栏点击“+”添加扫描目录，例如其他工具管理的安装目录。

## 迁移后如何更新 {#updates}

不同应用的更新方式并不相同。先看应用是否显示“锁定迁移”或相关更新提示。

| 情况 | 建议操作 |
| --- | --- |
| 更新被保护锁阻止 | 先退出应用，按 AppPorts 提供的提示处理；不确定时迁回本地更新，再重新迁出。 |
| 更新程序把新版重新装在本机 | 刷新列表；出现“待迁出”时，核对版本并迁出本地新版。 |
| App Store 管理的外置应用 | macOS 15.1 及以上可结合 App Store 的外置安装设置使用，仍需满足系统和应用条件。 |
| 较早系统上的 App Store 应用 | 在设置中确认是否允许迁移；更新后可能需要再次将本地新版迁出。 |

macOS 15.1 及以上可在 App Store 设置中选择“下载并安装大型 App 到独立存储盘”，并选择同一块外置盘。它是系统提供的安装方式，具体适用条件以 App Store 为准。

[更新保护的作用](/docs/migration-strategy/portal#updates)只针对需要保护的更新行为，不代表所有更新程序都以同样方式工作。

## 想迁回或恢复入口 {#restore-links}

- 把真实应用搬回内置盘：使用“迁移回本地”。
- 应用仍在外置盘，只缺本地入口：使用“链接回本地”。
- 只移除本地入口：点击本地列表中的垃圾桶按钮，提示为“断开此链接并删除文件”。

三种操作的区别和完整步骤见[还原、接回与解除链接](/docs/restore)。如果应用无法打开，先检查外置盘和[状态提示](/docs/badges)，再按[问题排查](/docs/faq#launch)处理。
