# 外接磁碟與日常使用

外接磁碟會成為遷移後應用或資料的實際存放位置。選擇連線穩定、空間足夠的裝置，比只看標稱速度更重要；需要頻繁啟動應用或讀寫小檔案時，外接 SSD 通常更合適。

## 哪些操作需要 APFS {#apfs}

| 要做的事 | 儲存要求 |
| --- | --- |
| 容器資料的掛載遷移 | 當前需要APFS 儲存，檢查通過後才能繼續。 |
| 普通應用、工具目錄或自選資料夾遷移 | 按所選內容、檔案系統能力和權限檢查，不能據容器要求一概判斷。 |
| NAS 或網路掛載位置 | 連線、檔案屬性與應用相容性各有差異；不作為容器 APFS 掛載遷移的替代方案。 |

若只是想遷移普通應用，不需要先為了容器功能重格式化整塊盤。格式不合適時，可以換一個目標，或讓容器資料留在本機。原因見[資料遷移方式](/docs/datamigrae/baseinfo)。

## 準備 APFS 儲存 {#prepare-apfs}

1. 先備份盤上已有內容，在“磁碟工具”中檢視裝置和卷的格式。
2. 已有合適的 APFS 儲存時，返回 AppPorts 選擇該位置並重新檢查。
3. 確需更改格式時，先確認備份可用，再按磁碟工具的說明操作。**抹掉磁碟會清除所選物件的資料**，不能把它當作普通的設定開關。

AppPorts 會為掛載遷移建立專用資料卷；通常無需自己為每個資料目錄預建卷或指定固定大小。

## 加密的外接磁碟 {#encrypted-drives}

2.0.0 支援在加密 APFS 目標上建立獨立加密的資料卷宗。遷移檢查後按「設定資料卷宗密碼」輸入並確認密碼，再繼續遷移；它不會繼承外接磁碟現有密碼，也不會更改原磁碟密碼和檔案。微信拆分遷移的多個新卷宗共用本次設定。

儲存到本機鑰匙圈以便連接外接磁碟後自動解鎖的選項預設勾選，可取消。儲存僅用於這台 Mac，不同步密碼；未儲存或鑰匙圈不可用時，需要手動解鎖，背景不會反覆彈出密碼框。密碼不寫入遷移記錄或日誌；未儲存的密碼在程序內暫存，結束後可能需要重新輸入。請妥善保存密碼，遺忘後無法恢復加密資料。

普通未加密 APFS 目標也能遷移，但磁碟遺失後他人可能讀取其中資料；同磁碟另一卷宗有密碼不代表新卷宗也已加密。查看遷移前提示並確認新卷宗的保護方式，不要為了通過檢查先解除已有加密。

## 外接磁碟是否記得檔案屬於誰 {#owners}

macOS 的某些儲存不保存檔案擁有者：exFAT 和 FAT32 沒有這個欄位；HFS+ 在以忽略擁有權的方式掛載時，新建檔案會被記成預留使用者。一般讀寫不受影響，但少數以管理員權限核對歸屬的應用（例如帶特權背景服務的 clash-verge）會拒絕工作，並給出 `chown` 修復建議——這條指令在這類卷上會被核心靜默丟棄，看似成功、實際無效。

APFS 即使在忽略擁有權的掛載下也保存真實歸屬，因此不在提示範圍。遷移一般資料目錄或自選資料夾時，AppPorts 會在確認框中說明目標磁碟的這個情況，不阻擋繼續。建議把這類應用的資料留在本機，或改用 APFS 格式的磁碟；HFS+ 可以在 Finder 的「顯示簡介」裡取消「忽略此磁碟區上的擁有權」後重新遷移。exFAT 沒有這個開關。

## 每天怎樣連線和斷開 {#daily}

- 使用前先連線外接磁碟，必要時開啟 AppPorts，確認資料狀態為“已掛載”或連結正常。
- 斷開前儲存工作，退出正在使用外接磁碟資料的應用，正常彈出儲存裝置。
- 重啟或重新插盤後，自動接回需要等待磁碟上線、解鎖和系統授權；不能保證早於所有登入應用。
- 移動或更新 AppPorts 後開啟一次，讓背景任務核對程式位置。

遷移不是備份。請檢查自己的備份工具是否覆蓋外接磁碟，尤其是重要的聊天記錄、專案和個人檔案。

## 空間、換盤和離線 {#space}

預留更新、複製和恢復所需的額外空間，不要只按當前資料夾大小把外接磁碟裝滿。APFS 卷可能共享空間，刪除或還原後的可用容量也可能稍後才更新。

換盤前先[還原到本地](/docs/restore#data)，再選擇新目標重新遷移。直接拖動受管資料或改卷名、目錄結構，可能讓已有入口失效。外接磁碟找不到、資料沒有接回時，先看[問題排查](/docs/faq#offline)。

## 外接磁碟上的簽名原包 {#signature-backups}

手動重簽官方應用後，外接磁碟可能出現可見的 `AppPorts Backups` 資料夾。AppPorts 自動選擇合適外接磁碟儲存完整官方原包，裡面的 `README.txt` 說明用途與刪除影響；應用仍在內建磁碟時也採用這一方式。恢復時需要接回儲存原包的盤，保留資料夾原位置。

原包不包含個人資料，也不是另一套獨立災備。內建磁碟應用重簽時仍需要臨時空間，跨卷儲存經核驗完成後才清理內部原件。選擇外接磁碟、檢視和清理的方法見[簽名原包說明](/docs/settings#signature-backups)。

## 從 AppPorts 退出整塊外接磁碟 {#eject}

1. 儲存工作，結束使用外接磁碟應用或資料的程式，等待進行中的檔案操作結束。
2. 在外接儲存區域的退出選單選擇「退出外接磁碟」。此操作針對**整塊實體磁碟及其所有卷宗**，包括接到本機資料目錄的專用卷宗，不只是目前選取的應用庫。
3. AppPorts 先暫停該磁碟的自動掛載，再請求 Finder 退出。已發出請求不代表已經退出；按系統結果和選單狀態確認後再拔除。
4. 仍有卷宗掛載或系統拒絕時，結束佔用程式後使用「重試退出」，不要強行拔除。

主動退出後，即使取消了 Finder 的退出或全部卷宗已卸載，自動掛載仍保持暫停。**拔下並重新插入裝置**，識別到同一磁碟的新連接後才會恢復；重新整理列表、重開 AppPorts 或等待逾時都不代替重插。沒有手動取消暫停並恢復掛載的按鈕。出現權限錯誤時，檢查 Finder 自動化權限並保留提示。
