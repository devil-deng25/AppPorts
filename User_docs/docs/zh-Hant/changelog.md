# 更新日誌

這裡記錄各版本當時的變化。**歷史條目中的功能可能已經停用，不應直接當作當前操作步驟。** 當前正文按 2.0.0（build 50）整理；舊功能的行為、版本和替代方法儲存在[歷史功能歸檔](/docs/archive/overview)。

## v2.0.0 {#v2-0-0}

以下依據目前 **2.0.0 build 50** 的程式碼與介面整理；版本號不代表已在下載管道發布。

- 微信帳號支援全部遷移或僅媒體拆分遷移，資料庫與設定可保留本機；切換方式前需完整還原。
- 支援加密 APFS 目標，為新資料卷宗獨立設定密碼，可選儲存到本機鑰匙圈；未儲存時需手動解鎖。
- 增加外接磁碟應用索引排除與大小快取重新整理，減少重複搜尋入口，並能核對快取時間。
- 新增「任務中心」，統一查看應用、資料、工具和自選目錄任務，支援加入背景、暫停、繼續、取消及歷史管理；資源衝突的任務排隊處理。
- 總體進度改為包含各階段的估算，目前目錄單獨顯示準備、掃描、複製、驗證、切換和收尾；多目錄任務不再用總體百分比代替目前階段。
- 異常處理區分重試、稍後處理和保留舊副本；應用異常另提供明確確認的結束任務及不做內容驗證的強制回遷。
- 新增整塊外接磁碟退出入口，先暫停自動掛載再請求 Finder 退出；重新插入裝置後恢復自動掛載。
- 資料遷移或遷回期間，更新後的原生 macOS 啟動入口會提示等待，減少誤開啟；不能涵蓋直接啟動真實應用等其他方式。
- 目標磁碟能力提示說明無法儲存的應用檔案屬性，可從提示開啟對應說明頁；普通應用與容器掛載遷移的儲存要求分別說明。
- 調整資料掃描和小檔案複製的並行讀取，保留內容驗證、入口切換前檢查與安全清理；不承諾所有儲存上的固定提速。
- 延續遷移與手動簽名分離、外接磁碟儲存官方原包，以及所有系統停用登入自動重簽的方式；補齊新增介面的多語言提示。

## v1.9.1（開發階段記錄） {#v1-9-1}

以下保留先前 **1.9.1 build 31** 開發階段的變更記錄，這些行為已由 2.0.0 延續：

- 應用資料列表預設隱藏不可遷移的鎖定結構，可開啟“顯示鎖定目錄結構”檢視原因；狀態統計支援篩選，個人目錄快捷入口單獨標識，不再計入應用資料大小或提供遷移操作。
- 遷移進度分別顯示準備、複製、校驗和收尾等階段。複製百分比到達 100% 後，仍需等待整次操作完成；長時間沒有進展時會顯示最後活動資訊。
- 資料遷移與手動重簽名分開，遷移不再自動附帶簽名操作。
- 手動重簽前的完整官方原包自動儲存到外接磁碟可見的 `AppPorts Backups` 資料夾，附中英文說明；無需選擇新位置，沒有合適外接磁碟時在修改正式應用前停止。內建磁碟應用操作時仍需臨時空間。
- 舊內建磁碟有效原包在條件滿足時自動遷出，冗餘原包和失效舊記錄按核驗結果清理；仍有恢復價值或來源不明的材料繼續保留，外接磁碟離線不視為備份丟失。
- 簽名選單隨狀態變化：已重簽的應用保留“恢復原始簽名”，隱藏重複重簽入口；恢復官方狀態後重新顯示符合條件的重簽操作。
- 所有 macOS 版本停用開機自動重簽名，並移除常駐設定卡。開啟 AppPorts 時處理舊登入任務，僅清理失敗時顯示重試。
- 加強複製核驗和容器結構保護，在切換或清理前再次檢查資料狀態。
- 保留經核對的原始應用恢復材料，區分“簽名已替換”與“簽名待檢查”，透過修復面板處理舊遷移。
- 修復官方原包驗籤失敗後仍可能繼續重簽的問題；校驗失敗或超時會停止。改進簽名中斷後的恢復，避免已撤回的操作被背景繼續提交，或對已完成操作重複重簽。

## v1.8.0 {#v1-8-0}

### 新功能 {#v1-8-0-features}

- 新增自定義本地掃描目錄：「Mac 本地應用程式」標題欄新增「+」按鈕，可新增額外的本地應用掃描目錄。適用於 JetBrains Toolbox、Steam 等將應用安裝在非 `/Applications` 目錄的工具。新增的目錄會持久儲存，並自動監控檔案變化（#48）。
- 新增 Stub Portal 版本自動同步：外接硬碟上的應用透過 App Store 更新後，本地 Stub Portal 的版本資訊會自動同步更新，並重新整理 macOS Launch Services 快取，「開啟方式」選單不再顯示舊版本號（#50）。
- 新增工具目錄識別：支援 Gradle（`~/.gradle`）、Android 開發資料（`~/.android`）和 Flutter/Dart Pub 快取（`~/.pub-cache`）（#49）。
- 新增目錄遷移：可在「目錄遷移」標籤中新增任意使用者資料夾，將大型專案、模型、素材庫或工具快取遷移到外部儲存，並支援接回和還原（#54）。
- 新增受保護應用遷移預警：遷移 App Store 應用或 root 歸屬應用前，會提示這類應用可能因權限不足無法自動刪除或替換，並建議先透過 Finder 手動遷移後再建立連結（#55）。

### 改進 {#v1-8-0-improvements}

- 應用掃描效能最佳化：每個應用的 Info.plist 讀取次數從 7 次降低到 1 次（透過記憶體快取），整體掃描速度顯著提升。
- 掃描超時保護：codesign 子程序新增 10 秒超時，避免大型應用簽名檢查卡死導致掃描掛起。
- 目錄體積計算安全上限：遞迴計算應用體積時新增 50 萬檔案數量上限，防止 Electron 等超大應用包無限遍歷。
- 掃描過程可追蹤：掃描迴圈新增逐應用 TRACE 日誌，便於定位掃描卡在哪個應用。
- 資料目錄掃描精準匹配：修復 bundle ID 字尾提取邏輯，過濾 app、com、org 等通用詞彙，避免誤匹配系統容器目錄導致掃描變慢。
- 工具目錄接回檢測更完整：本地工具目錄缺失但外部儲存規範位置仍有受管目錄時，會顯示「待接回」；切換外部儲存會自動重新整理工具目錄狀態。
- 本地化與無障礙完善：應用/資料目錄/自定義目錄狀態、排序與篩選標籤、設定開關和狀態徽章會更穩定地跟隨當前語言，並提供更明確的輔助功能標籤。
- 應用體積改為會話級快取，減少重新整理後重新顯示「計算中」或體積丟失的情況（#55）。
- 資料目錄遷移回滾更安全：建立連結前先把本地源目錄改名為隱藏安全備份；建立連結或清理備份失敗時會盡量保留本地備份和外部副本，避免兩端資料同時丟失（#54）。

### 修復 {#v1-8-0-fixes}

- 修復 Trae 等應用掃描極慢的問題 — bundle ID 中的通用字尾 `app` 導致 `~/Library/Containers/` 下大量不相關目錄被誤掃描。
- 修復外接硬碟應用透過 App Store 更新後，本地 Stub Portal 版本資訊不更新、「開啟方式」選單顯示舊版本的問題。
- 修復點選重新整理按鈕不會觸發 Stub Portal 版本同步的問題。
- 修復資料目錄接回或規範化時可能把外部普通檔案當作目錄處理的問題；現在會拒絕普通檔案並保留原檔案。
- 修復多行彈窗正文在部分語言下回退顯示中文的問題，並補全俄語介面翻譯；Stub Portal 的「外部儲存未連線」系統彈窗也會按系統語言顯示（#55）。

## v1.7.0 {#v1-7-0}

### 新功能 {#v1-7-0-features}

- 新增「待遷出」狀態：當本地真實應用版本高於外部儲存中的同名應用時，AppPorts 會標記為「待遷出」，提示可將本地新版遷移到外部儲存並替換舊副本。
- 新增資料遷移重簽名確認：遷移應用容器內資料前，可選擇是否在遷移完成後自動對關聯應用執行 Ad-hoc 重簽名，以降低容器資料遷移後應用無法識別資料、提示異常或啟動異常的風險（#44）。 **此處記錄舊版行為，自動簽名流程現已停用，見[歸檔](/docs/archive/data-signing)。**

### 介面改進 {#v1-7-0-ui}

- 頂部工具欄重排：應用頁和資料目錄頁切換按鈕改為更緊湊的圖示 + 文字樣式，減少空間佔用。
- 資料目錄頁操作欄最佳化：「工具目錄 / 應用資料」切換、遷移後重簽名開關、恢復原始簽名按鈕和重新整理按鈕統一放入頂部工具欄。 **此處記錄舊版行為，自動簽名流程現已停用，見[歸檔](/docs/archive/data-signing)。**
- 應用狀態徽章新增「待遷出」，方便識別本地版本高於外部舊副本、可以遷出替換的應用。
- 資料目錄遷移重簽名確認彈窗完成本地化，標題、正文和按鈕會跟隨當前語言顯示。 **此處記錄舊版行為，自動簽名流程現已停用，見[歸檔](/docs/archive/data-signing)。**

### 改進 {#v1-7-0-improvements}

- 應用遷移安全策略增強：外部目標已存在時，僅在目標被識別為 AppPorts 管理的舊入口、舊遷移殘留，或當前應用處於「待遷出」狀態時，才會自動清理並繼續遷移。
- 資料目錄恢復校驗增強：不再使用目錄大小接近作為自動恢復依據，必須完整匹配 AppPorts metadata 後才會自動接回或恢復。
- 應用資料掃描更穩定：快速切換應用時，舊掃描任務結果不會覆蓋當前選中應用的資料目錄列表。
- 管理員命令和 AppleScript 轉義增強：路徑包含引號、反斜槓、空格或中文時，Finder 刪除和管理員修復權限命令會更安全地處理。
- 本地化完善：修復切換語言後部分幫助內容、提示彈窗和資料遷移確認內容仍顯示中文或翻譯不完整的問題，並補齊所有支援語言的相關翻譯（#43）。

### 修復 {#v1-7-0-fixes}

- 修復資料目錄遷移可能將外部真實目錄誤判為可恢復目標的問題。
- 修復應用遷移時可能錯誤刪除外部同名真實應用的問題。
- 修復外部舊 AppPorts portal / 舊遷移殘留無法被穩定識別和清理的問題。
- 修復路徑包含特殊字元時 AppleScript 或管理員命令可能構造錯誤的問題。
- 修復應用資料遷移流程中，背景遷移或遷移後重簽名可能讀取到已切換應用的問題。 **此處記錄舊版行為，自動簽名流程現已停用，見[歸檔](/docs/archive/data-signing)。**
- 修復「待遷出」狀態未在應用列表中顯示狀態徽章的問題。
