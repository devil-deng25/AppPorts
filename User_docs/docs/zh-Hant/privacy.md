# AppPorts 隱私政策

更新日期：2026 年 10 月 15 日

生效日期：2026 年 10 月 15 日

適用版本：AppPorts 1.8.1 及後續版本

AppPorts（以下稱“本軟體”）是一款執行於 macOS 平臺的應用程式遷移工具。本隱私政策（以下稱“本政策”）闡釋我們如何收集、使用、共享與保護您的個人資訊，以及您就此享有的權利。

本政策適用於本軟體，以及我們的官方網站（appports.shimoko.com）與使用者文件站（docs-appports.shimoko.com）。除本政策外，我們在需要讀取您資訊的各項功能中，還會以相應的頁面提示向您說明該功能的資訊處理規則。

請您在使用本軟體或訪問前述站點前，仔細閱讀並充分理解本政策全部內容。您開始使用本軟體或訪問前述站點，即表示您已閱讀、理解並同意本政策。本政策不適用於第三方如何定義或使用您的個人資訊，我們建議您在與其互動之前先行閱讀其隱私政策。

## 第一條  定義 {#section-1}

本政策中下列用語的含義為：

- 個人資訊：指以電子或者其他方式記錄的與已識別或者可識別的自然人有關的各種資訊，既包括可直接識別您身份的資訊（如姓名），也包括不能直接識別、但可透過合理推斷間接識別您身份的資訊（如裝置序列號），不包括匿名化處理後的資訊。
- 彙總資料：指經統計處理後無法識別特定自然人的資料。就本政策而言，彙總資料不屬於個人資訊。
- 個人資訊處理：指個人資訊的收集、儲存、使用、加工、傳輸、提供、公開、刪除等行為。
- 您：指本軟體的終端使用者以及前述站點的訪問者。
- 我們：指本軟體的開發者與運營者。

## 第二條  適用範圍 {#section-2}

本政策適用於您透過本軟體、官方網站與使用者文件站與我們發生的各項互動。官方網站與使用者文件站均為靜態站點，不設使用者帳號體系，亦不提供使用者生成內容功能。

本政策不適用於前述站點所連結的第三方服務，該等第三方服務由其各自的隱私政策約束。

## 第三條  我們的承諾 {#section-3}

我們堅信並尊重基本隱私權，並認為這些權利不應因您所在的國家或地區而有所不同。

基於上述理念，我們不設計任何以犧牲隱私為代價的功能：本軟體的核心功能完全在您的裝置本地完成，我們不設帳號體系，不採集使用行為，不進行個性化推薦。若某項功能的實現確需讀取您的資訊，我們會在本政策或該功能的頁面中明確告知其範圍與目的。

## 第四條  我們收集與使用的個人資訊 {#section-4}

我們不收集、不使用、不對外提供您的任何個人資訊，亦不在伺服器端保留任何與您相關的資料。具體而言：

- 本軟體不設帳號體系，不提供註冊、登入功能，不收集手機號碼、電子郵箱、姓名等身份資訊；
- 本軟體不整合任何統計分析、行為追蹤、A/B 測試或崩潰收集類軟體開發工具包；
- 本軟體不整合任何廣告或訊息推送類軟體開發工具包，不進行個性化廣告投放；
- 本軟體不生成、不讀取任何裝置識別符號（如 IDFA、IDFV、硬體序列號、硬體 UUID）；
- 本軟體不申請、不獲取通訊錄、日曆、提醒事項、照片、麥克風、攝像頭、定位、藍芽、健康等任何系統權限；
- 本軟體僅在您選擇儲存加密資料卷宗密碼時讀寫本機登入鑰匙圈中的對應項目，不讀取其他應用的密碼；
- 本軟體不為統計分析或廣告目的設定、讀取 Cookie。

## 第五條  本軟體在本機讀取的資訊 {#section-5}

為實現“將應用程式及其資料遷移至外部儲存介質”這一核心功能，本軟體需在您的裝置本地讀取下列資訊。上述讀取行為均在本機完成，不構成向任何第三方提供個人資訊：

- 應用程式目錄（如 /Applications）中的應用程式包、圖示及其程式碼簽章資訊；
- ~/Library 目錄下與應用程式相關的資料目錄，用於識別可遷移的資料並計算其佔用空間；
- 您自行新增的自定義掃描路徑；
- 您指定的外部儲存介質路徑，用作遷移目標位置及連結狀態校驗；
- 已連線儲存卷的標識、連線型別、可寫狀態和剩餘空間，用於核對遷移位置，並在需要儲存簽名原包時自動選擇合適外接磁碟；
- 當前正在執行的應用程式列表，用於在遷移前確認目標應用程式未處於執行狀態，以避免資料損壞；
- 裝置基本執行資訊，包括 macOS 版本、處理器核心數、實體記憶體容量以及外部儲存介質讀寫速度，僅用於生成本地日誌與遷移效能報告。

## 第六條  網路訪問與資訊接收方 {#section-6}

本軟體僅在下列情形下發起網路請求，且請求內容不包含您的任何個人資訊，亦不包含帳號標識、裝置標識、檔案路徑及檔名稱：

- 版本檢查：本軟體在啟動時進行一次靜默版本檢查，或依您的操作發起檢查，請求地址為 appports.shimoko.com/latest.json；同時查詢 GitHub 平臺上的版本資訊（api.github.com），在該介面不可用時回退至 github.com 提供的 releases.atom 地址。
- 資訊展示：在您開啟“關於 AppPorts”視窗時，本軟體請求 GitHub 平臺的貢獻者名單，以及使用者文件站的贊助者名單（docs-appports.shimoko.com/sponsors.json）。

上述請求僅攜帶固定的 User-Agent 標識（AppPorts 或 AppPorts-UpdateChecker）。基於 HTTP 協議的固有屬性，接收方伺服器可獲取您的 IP 地址與請求時間。前述接收方為 GitHub 平臺及本專案使用者文件站的伺服器，其個人資訊處理行為分別適用其各自的隱私政策。

下列行為不由本軟體自行實施，而是交由您的預設瀏覽器完成：下載新版本；開啟官方網站、使用者文件、程式碼倉庫及贊助頁等外部連結。

## 第七條  資訊的本地儲存 {#section-7}

本軟體在您的裝置本地儲存下列檔案與配置，相關內容不涉及個人資訊的對外提供：

- ~/Library/Application Support/AppPorts/AppPorts_Log.txt：操作日誌與診斷資訊；
- 本機登入鑰匙圈：僅在您選擇儲存時保存對應加密資料卷宗的密碼，不同步；密碼不寫入日誌或遷移記錄，未儲存時僅在程序內暫時使用；
- 應用和工具目錄大小快取、應用搜尋位置記錄：用於顯示大小、快取時間及維護應用庫和本機入口；不上傳檔案清單；
- `migration-task-history.json`：任務名稱、類別、相關路徑、時間和顯示結果；僅用於任務歷史，不是自動重新執行的佇列；
- `disk-ejection-pauses.plist` 與 `launch-locks`：分別儲存主動退出磁碟後的掛載暫停資訊，以及供本機程序協調遷移期間啟動保護的鎖定檔案；不會上傳；
- ~/Library/Application Support/AppPorts/contributors-cache.json：貢獻者名單快取，用於減少重複的網路請求；
- ~/Library/Application Support/AppPorts/sponsors-cache.json：贊助者名單快取，用於離線狀態下展示；
- ~/Library/Application Support/AppPorts/ 下的遷移、掛載、簽名與恢復記錄：儲存應用身份、相關路徑、卷標識及操作狀態，用於接回資料、恢復簽名和繼續未完成的操作；
- 外接磁碟根目錄的 AppPorts Backups 資料夾：自 1.9.1 build 31 起，自動儲存手動重簽前經核對的官方應用原包，內附 README.txt；這些原包用於恢復應用內容和簽名，不是聊天記錄、文件等個人資料的備份；
- ~/Library/Preferences 目錄下的偏好設定檔案：介面語言、外部儲存路徑、自定義掃描路徑及各項功能開關。

重簽過程中還會在真實應用旁建立臨時工作副本；仍有恢復價值的舊內建磁碟原包，會在滿足條件並完成外接磁碟複製核驗後遷出。原包、索引和上述操作記錄均儲存在本地儲存裝置，不會因儲存或自動維護而上傳。

您可以刪除快取、日誌和偏好設定。刪除遷移或恢復記錄前，請先透過本軟體完成相關還原與收尾，避免丟失資料接回或簽名恢復所需的資訊。解除安裝本軟體不會自動還原已遷移的資料，也不會自動刪除外接磁碟上的應用、資料或簽名原包。原包的保留與刪除影響見[簽名原包說明](/docs/settings#signature-backup-cleanup)，解除安裝步驟見[刪除 AppPorts 前要做什麼](/docs/faq#uninstall)。

## 第八條  診斷包 {#section-8}

“匯出診斷包”功能僅在您主動點選後執行，並且：

- 匯出檔案的儲存位置由您在系統儲存面板中自行選擇；
- 匯出前，本軟體會將日誌中的使用者名稱替換為 ~，將 /Users/＜使用者名稱＞ 替換為 /Users/＜redacted-user＞，並對您的外部儲存介質名稱作脫敏處理；
- 本軟體不會自動上傳該檔案，亦不會將其提供給任何第三方。是否將其提供給我們，完全由您自行決定。

## 第九條  系統權限 {#section-9}

為實現上述功能，本軟體可能涉及下列系統權限：

- 完全磁碟訪問權限：用於讀寫 /Applications 及 ~/Library 下的相關目錄。該權限需由您在“系統設定 - 隱私與安全性”中手動開啟，本軟體無法自行申請，亦無法繞過該權限限制。
- 自動化權限（Apple 事件）：在遷移 App Store 應用程式時，本軟體透過 Finder 完成移動或刪除操作。macOS 將就此向您徵求同意，您有權拒絕，並可隨時在“系統設定 - 隱私與安全性 - 自動化”中關閉該權限。
- 管理員權限：僅在您對歸屬 root 使用者安裝的應用程式執行重新簽名或修復所有權時觸發。您輸入的管理員密碼由 macOS 系統對話方塊直接提交至作業系統，本軟體不讀取、不記錄、不儲存該密碼。

本軟體未申請通訊錄、日曆、照片、麥克風、攝像頭、定位、藍芽等任何權限，僅在您選擇儲存加密資料卷宗密碼時使用本機登入鑰匙圈中的對應項目。

本軟體未啟用 App Sandbox（因需跨磁碟讀寫應用程式與資料目錄），但已啟用 Hardened Runtime。發行版本未經 Apple 公證，首次執行時您可能需要在“系統設定 - 隱私與安全性”中手動允許。

## 第十條  Cookie 與同類技術 {#section-10}

我們的官方網站（appports.shimoko.com）與使用者文件站（docs-appports.shimoko.com）均為靜態站點，不使用 Cookie 進行統計分析，不包含第三方廣告或社交外掛，也不設定跨站跟蹤畫素。

兩個站點均使用開源統計工具 Umami 統計頁面訪問量，以便了解各頁面的使用情況並改進內容，其處理規則如下：

- 不使用 Cookie，不採集可識別您個人身份的資訊，不進行跨站追蹤；
- 不儲存您的原始 IP 地址，該地址僅在請求發生時用於判斷粗略地區並對訪問去重；
- 僅記錄頁面訪問量、來源站點、瀏覽器與作業系統型別、粗略地區等彙總資料；
- 您可以隨時透過瀏覽器的內容攔截擴充套件或網路過濾器遮蔽該指令碼，此舉不影響頁面的正常訪問與閱讀。

若您所在國家或地區的法律將 IP 地址或類似標識視為個人資訊，我們將以同等標準對待此類標識。

站點託管服務商可能基於運維與安全防護的需要保留常規訪問日誌。

## 第十一條  贊助者資訊的公開 {#section-11}

當您透過贊助二維碼支援本專案，並在留言中填寫暱稱時，暱稱將公開顯示於使用者文件站贊助頁及本軟體“關於 AppPorts”視窗的贊助者區塊。個人連結為選填，未提供時僅展示暱稱；贊助金額僅在網站贊助頁展示。

上述情形是本專案中唯一涉及個人資訊公開的場景，且以您的自願提供為前提。若您不希望暱稱或連結被公開，可在贊助時不作填寫，或依第十八條載明的方式要求更正、刪除。

## 第十二條  第三方平臺 {#section-12}

在下列情形中，相關資訊的處理由第三方平臺獨立進行，適用其各自的隱私政策，我們不對第三方的資訊處理行為負責：

- 您透過 GitHub 平臺提交 Issue 或 Pull Request 時，相關資訊由 GitHub 處理；
- 您透過 Bilibili、微信、支付寶等平臺進行贊助時，支付相關資訊由該等平臺處理，我們不接觸您的支付帳號資訊；
- 您透過本軟體或前述站點開啟第三方連結時，該第三方站點可能自行收集您的資訊。

## 第十三條  個人資訊的跨境傳輸 {#section-13}

本軟體不在伺服器端收集或儲存您的個人資訊，因此不涉及由我們發起的個人資訊出境活動。

當您透過 GitHub、Bilibili 等平臺與我們互動時，相關資訊可能由該等平臺傳輸至其所在國家或地區的伺服器，該等傳輸與處理由其依其隱私政策獨立完成。

## 第十四條  未成年人保護 {#section-14}

本軟體不面向未成年人設計，不會主動收集未成年人的個人資訊。若您是未成年人，請在監護人的陪同下閱讀本政策，並在取得監護人同意後使用本軟體。

## 第十五條  資訊保安 {#section-15}

鑑於本軟體不在伺服器端收集或儲存您的個人資訊，不存在因伺服器資料洩露而導致您的個人資訊外洩的風險。本軟體在本機讀取與寫入的檔案，其安全性依賴於您的裝置與作業系統自身的安全防護措施，我們建議您妥善保管裝置並保持系統更新。

## 第十六條  您的隱私權 {#section-16}

我們尊重您獲知、訪問、更正、傳輸、限制處理與刪除個人資訊的能力。由於我們不收集、不儲存您的個人資訊，我們不掌握可供查詢、更正或刪除的個人資訊；但我們保障您就本政策與我們溝通的權利，並承諾不因您行使上述權利而對您作任何區別對待。

若我們在任何情形下需以您的同意作為個人資訊處理的合法性基礎，您有權隨時撤回該同意，且撤回同意不影響撤回前基於您的同意已進行的處理活動的效力。

您可以透過下列方式行使您的權利：

- 按第七條說明管理或刪除本地快取、日誌、配置及恢復材料；刪除前先處理仍由本軟體管理的遷移，不將解除安裝軟體視為外接磁碟資料已被刪除；
- 就已公開的贊助者資訊，隨時依第十八條載明的方式要求更正或刪除；
- 若您認為我們的個人資訊處理行為損害了您的合法權益，您有權向有關監管部門投訴、舉報。

## 第十七條  政策更新 {#section-17}

我們可能適時修訂本政策。修訂後，本頁面頂部的“更新日期”與“生效日期”將同步更新。涉及您權利實質變更的重大修訂，我們將在版本更新日誌及 GitHub Release 說明中予以提示。

本政策以簡體中文版本為準，其他語言譯本僅供參考。
