# 簡介

AppPorts 是一款免費、開源的 macOS 應用與資料遷移工具。它幫助你把佔空間的應用、應用資料和自己的資料夾放到外部儲存，並管理本地入口、接回和還原。你可以保留需要的內容，同時為 Mac 的內建儲存騰出空間。

應用和資料可以分別遷移。例如，你可以只搬走一個大型應用，也可以把應用留在本機，只遷移它支援遷移的資料目錄。不同內容有不同的限制，AppPorts 會根據所選專案提供相應操作。

## AppPorts 的產品哲學 {#philosophy}

| 原則 | 對使用意味著什麼 |
| --- | --- |
| 透明體驗 | 儘量保留熟悉的開啟方式，讓應用搬到外接磁碟後仍能從本地入口啟動。 |
| 策略穩定 | 優先採用經過驗證的方式；遇到無法確認的資料、權限或目標衝突時，先說明問題。 |
| 低系統負擔 | 減少不必要的背景工作；掛載資料需要的登入和重連任務按實際狀態執行。 |
| 廣泛國際化 | 讓更多語言的使用者能夠使用 AppPorts，並持續改善翻譯。 |
| 無障礙友好 | 為介面操作、狀態提示和輔助技術提供支援。 |

這些原則也意味著保留選擇：只遷移應用的使用者不必先研究容器資料；不滿足掛載條件時，可以讓資料繼續留在本機。遷移後的內容仍依賴外接磁碟，重要資料也仍需要備份。

## 開始之前 {#before-start}

先了解要搬的是應用本體還是應用資料，再確認外接磁碟和權限。AppPorts 不會把不支援的目錄變成可遷移目錄，也不能保證任意應用在任意儲存裝置上都能照常工作。
