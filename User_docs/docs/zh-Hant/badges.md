# 徽章與狀態

徽章說明專案現在的狀態，不是一次完整的健康檢查。先看文字，再決定是否需要處理；可點選的徽章會補充說明。不同版本可能顯示不同組合。

## 應用位置與更新保護 {#apps}

| 看到的徽章 | 表示什麼 | 接下來怎麼做 |
| --- | --- | --- |
| 本地 | 應用在 Mac 上，沒有其他需要顯示的標籤。 | 想釋放空間時再遷移。 |
| 已連結 | 已有指向外部應用的本地入口。 | 連線外接磁碟後正常使用。 |
| 鎖定遷移 | 已連結，併為需要保護的應用啟用了更新保護。 | 更新前閱讀[應用更新說明](/docs/core#updates)。 |
| 非鎖定遷移 | 此應用需要更新保護，但目前未鎖定。 | 點選瞭解原因；更新前先確認處理方式。 |
| 部分連結 | 資料夾內只有部分應用或元件已連結。 | 展開或檢視對應專案，逐項確認。 |
| 孤立連結 | 本地入口還在，目前找不到外部目標。 | 先連線原外接磁碟並重新整理，不能據此斷定檔案已刪除。 |
| 未連結、外部 | 外部應用尚無可用的本地入口。 | 需要時使用“連結回本地”。 |
| 待遷出 | 識別到本地真實應用比外部副本更新。 | 核對版本和目標，再將本地新版遷出。 |

“鎖定遷移”保護的是特定更新場景，並不替代備份。“待遷出”也不是必須立即執行的命令。

## 應用型別 {#types}

| 徽章 | 含義與注意事項 |
| --- | --- |
| 執行中 | 應用正在執行，遷移或還原前先儲存並退出。 |
| 系統 | macOS 系統應用，通常不適合遷移。 |
| 非原生 | 在 Mac 上執行的 iPhone／iPad 應用。支援範圍受裝置與系統限制。 |
| 商店 | 來自 App Store，或由系統管理外接安裝。支援時可點選檢視說明。 |
| Sparkle、Electron | 應用使用的技術框架。它們有助於判斷更新方式，不表示遷移已經成功。 |

## 簽名狀態 {#signing}

| 徽章 | 含義 | 建議 |
| --- | --- | --- |
| 簽名已替換 | 檢測到原開發者簽名被本地重簽替換。 | 開啟“修復”或“檢視修復步驟”，按[升級與修復](/docs/macos-27)處理。 |
| 簽名待檢查 | 當前簽名或恢復材料的檢查沒有得到可靠結果。 | 先連線外接磁碟，點選“檢查簽名”檢視結果並保留備份；持續出現時提供診斷資訊。 |
| 已重簽名 | 當前識別為本地重簽狀態，但未歸入上述開發者簽名替換提示。 | 不代表已恢復官方身份，也不保證容器資料能訪問。 |

簽名狀態與資料位置是兩回事。“已掛載”不能證明應用簽名正常，“簽名已替換”也不能證明資料損壞。

已確認重簽的應用，右鍵選單保留“恢復原始簽名”，不再同時提供重複重簽入口；檢查結果不明時先檢查簽名。新儲存的官方原包在外接磁碟，恢復前需接回儲存它的盤，見[簽名與修復](/docs/settings#manual-signing)。

## 資料目錄與自選資料夾 {#data}

| 狀態 | 表示什麼 | 接下來怎麼做 |
| --- | --- | --- |
| 本地 | 資料仍在本機。 | 核對用途後決定是否遷移。 |
| 已連結 | 原目錄透過符號連結訪問外部資料。 | 保持外接磁碟線上。 |
| 已掛載 | 外部資料卷已接到原目錄。 | 開啟應用檢查實際讀寫。 |
| 待掛載 | 已找到資料卷，但尚未接到原目錄。 | 使用“掛載”。 |
| 外接磁碟未連線 | 暫時找不到受管資料卷。 | 連線原盤並檢查卷是否可用。 |
| 待接回 | 外部資料仍在，本地入口需要重建。 | 核對目標後使用“接回”。 |
| 待規範 | 識別到受管連結，但位置需要整理。 | 閱讀“整理”的確認說明；舊容器連結另見[經典模式](/docs/classic-mode)。 |
| 現有軟連結 | 已有符號連結，尚未按 AppPorts 的方式管理。 | 核對真實目標，按可用操作處理。 |
| 使用者目錄入口 | 容器中指向桌面、下載、圖片等個人目錄的快捷入口，並非此應用獨佔的資料。 | 不統計目標大小，也不提供遷移或還原；不要把它當作普通空資料夾。 |
| 孤立連結 | 自選資料夾的連結目標暫時不可達。 | 先檢查外接磁碟、路徑和連線。 |
| 未找到 | 配置中的目錄目前不存在。 | 核對原位置，不要先新建同名空目錄。 |
| 外部 | 自選資料夾的資料位於外部位置。 | 結合本地一側狀態判斷是否需要接回。 |
| 目標衝突 | 目標位置已有其他內容。 | 確認兩份內容的歸屬，不能直接覆蓋。 |
| 保留副本 | 操作後還有需要保留或繼續清理的副本。 | 按完成提示收尾，先確認有效資料在哪。 |

## 重要、推薦、可選 {#priority}

這是資料目錄的重要程度提示，不是遷移成功率：**重要**表示影響應用核心功能，**推薦**表示通常有較大空間收益，**可選**表示可能較小或可重建。遷移任何一類都需要先退出相關程式。

例如，“推薦 + 本地”只是說這個本地目錄值得檢視；“已連結 + 執行中”則說明外部應用正在使用。需要改變存放位置或恢復入口時，見[還原、接回與解除連結](/docs/restore)。
